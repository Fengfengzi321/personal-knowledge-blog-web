# Knowledge Map Behavior

## Version 1 Pattern

Use a personal blog-style homepage with avatar, site intro, topic links, and a recent-articles list.

## Homepage Layout

- Circular avatar image (`/avatar.jpg`).
- Site name and tagline.
- Topic pill links — quick access to topic pages.
- Word count display.
- Recent Posts section — last 5 published articles.
- "Read More →" link to the full posts listing.

## Navigation Requirement

A reader can reach any public article from the homepage within 2-3 clicks:

1. Homepage → Recent Posts / Read More → `/posts/`
2. Posts list → individual article `/articles/:slug/`
3. Top tab bar → Tags / Search / Topics

## Mobile Requirement

On narrow screens, the layout stacks vertically with readable font sizes and adequate spacing.
